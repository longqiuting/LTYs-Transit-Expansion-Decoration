# LTE 拆分计划 · 已定约束（2026-11-22）

> 状态：**只记录，未动工**。可行性调研（代码切面 / MTR3-4 / Fabric-Forge）单独进行中。

## 1. 拆分目标

| 产物 | 内容 | 归属 |
|---|---|---|
| **LTE（优化版）** | 只保留对原版 MTR 的优化：灯光 / 光束 / 散射、轨道碰撞、列车碰撞、轨道床、**连接器** | 独立维护（**yomi 已确认不整合进 YMTR**） |
| **LTED**（LTY's Transit Expansion Decoration） | 其余全部装饰内容：厦门系列方块、时钟、装饰物件、PIDS、屏蔽门 LCD、安全设备等 | 本仓库继续 |

## 2. 命名空间约束（硬性）

- **LTED 必须继续使用 `mtrlte` 命名空间**，方块/物品 id 一律不改——否则存档里已放置的方块会变成未知方块而消失。
- 允许改的只有**模组 id / 显示名**（`fabric.mod.json` 的 `id`、lang 里的模组名）。
- 优化版（拆出去的 LTE）使用**新的命名空间**，不与 `mtrlte` 冲突。

## 3. 创造模式页签调整

- `lte_logo` 方块与贴墙标识方块从"LTE"页**移到厦门地铁物件那一页**，位置为**开头两位**（第一个、第二个）。
- 其余 LTE 页签内容（灯光编辑器、连接器、仪表板等）留在优化版。

## 3.5 版本口径与图标（已定）

- 1.20.1 跟随 **YMTR 3.6.x**；1.18.2 / 1.19.2 / 1.19.4 跟随**上游 MTR 3.2.2**。
- MTR4 支持等其稳定后再做。
- LTED 图标：`art/LTED-icon.png`（2048×2048）。
- 后续事项见 `docs/lted-roadmap.md`。

## 3.6 版本与仓库归属（2026-11-22 定）

- LTE 版本从 **3.x** 起（延续原版本线）。
- 仓库**保留在 longqiuting 账号下**（Yomi 意见），拆分完成后加 Yomi 为协作者，不做 transfer。
- 仪表板拆分方案见 docs/dashboard-split-plan.md。

## 4. 未定 / 待评估

- 四版（1.18.2 / 1.19.2 / 1.19.4 / 1.20.1）× MTR3/MTR4 × Fabric/Forge 的目标组合是否全部成立（取决于外部依赖是否有对应版本）。
- 两个模组之间是否还需要共享配置 / 联合安装检测（拆分后各自独立运行）。
