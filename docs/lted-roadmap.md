## 1. 待做事项（按用户列表编号）

### 4. 屏蔽门集控器（可与红石联动）

- 一个集中控制屏蔽门的方块/设备，支持红石信号联动（开关门、可能含分区控制）。
- 未定：控制范围（整站 / 按站台 / 按门组）、红石语义（上升沿开、断电关 / 保持 / 脉冲）、是否要 GUI 选择门组。

### 5. 纹理分级：LTED 默认低分辨率 + 内置资源包提供原清晰度

- **默认所有纹理压到低分辨率**，适配弱显卡（如 GTX 260 那类，`GL_MAX_TEXTURE_SIZE=8192`，且显存/带宽紧张）。
- 同时**内置一个资源包**（jar 内或随包分发），供性能足够的玩家切换回原清晰度。
- 参考实现思路：`cullleaves-fabric-4.1.1+1.20.1`（它是怎么把可选高分辨率资源作为内置包暴露的，去看它的结构：`resourcepacks` 入口、pack.mcmeta、是否用 `ResourceManagerHelper` 注册内置包）。
- 注意：**不能让低分辨率成为唯一**；也不能因为压缩导致 UI 文字/细线糊掉（PIDS/PSD-LCD 的位图是运行时生成，不受此影响，但方块贴图会）。

### 6. 修复内置轨道模型的贴图错误

- 现象：**内置（打包进 jar）的厦门风格轨道模型，贴图与"单独加载资源包"时不一致/错误**。
- 这一部分依赖 NTE（`mtrsteamloco`）的渲染路径，所以**同样要按第 5 条做成"可选高清资源包"**，而不是只修一次贴图了事。
- 备注：之前做过一版但做错了，尚未修复；修复时要对照资源包原版资源（`厦门风格物件包/assets/mtrsteamloco/rails/`）逐文件核对贴图引用与 UV。
